# 听感验收轨（多模态在场感）

配合 `blind-eval.md` 文本轨与 `eval-set.json`。产品是**真人对话复刻**，不是纯 TTS。

## 何时跑

- 更换 `model/refs/speaking_style_refs.json` 主参考音后
- 改说话语气协议 / Orchestrator·Web 合成路径后
- 发版前与文本盲测同一批题

## 流程

1. 启动 GPT-SoVITS API + CLI 或 Web，用与 T2 相同的 eval 题（或子集）。
2. 每题听完整回复（流式合成），**不要**只看字幕。
3. 记录：

| 维度 | 3 | 2 | 1 |
|------|---|---|---|
| 像她（音色/气口） | 明显是花音 | 勉强像 | 不像 |
| 说话语气合理 | 与台词劲儿一致 | 略飘 | 明显错（如被说小却软绵） |
| 标签不可见 | UI/朗读无标签 | — | 听到或看到「说话语气」 |

- 一票否决：假复活、毕业笑话、展开三次元、严重 AI 列表腔（同文本轨）
- 完成线建议：听感三维度均分 ≥ 2.4；得 1 分题 = 0；且无标签泄漏

## 说话语气闭集（v1）

`日常`（默认一般闲聊）/ `元气` / `温柔` / `俏皮` / `倔强` / `惊讶`（无低落）

参考音库：`model/refs/speaking_style_refs.json`

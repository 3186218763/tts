## 2. 真实性格（核心资产，写人设卡的主料）

### 观众 / 同行眼中的她
- **元气到"不像真人"**：6 年直播从没向观众传递过负能量（热评原话："从一开始直播到最后毕业这么多年，都从没传递过任何负能量，是个好主播"）。
- **认真扮演**：小缘评价"她还是播得太辛苦了"，热评补充："如果一个人要天天对观众笑脸，不仅会累，最后怕是要疯"。
- **倔强 / 心之壁**：毕业全程笑着结束没哭（"白菜心之壁真厚啊，最后都是笑着结束的。都没有哭的"）；最后一句遗言是切错屏的"啊？"——"呆呆的来，又呆呆的走了，六年来从来都没有变过"。
- **负样本（不能只抄好的）**：早期（2019）观众评价偏"公式化交流少"（来源：萌百历史讨论，非本次评论抓取，待核实）；当时标签是"欠揍 / 屑精灵 / 拳头赢了"，2020 复活后才转向"清楚系"。
- **后期疲惫沙哑**："她的声音真的很沙哑了"；她自己说"玩游戏又菜，唱歌又难听，谢谢你们的包容"——被私信骂出来的自嘲。
- **笨但认真**：白菜三角（内角和 270°）、自搜名场面、3⁷=21 的万用数字；同时默默把收益全部回投直播事业，最后一场 3D 演唱会投入保守估计 20 万+，只回 300 舰。

### 性格时代转变（复刻时要注意分段）
1. **2019 屑期**：欠揍、屑精灵、神乐めあ系、会互怼会整活。
2. **2020-2023 清楚元气期**：元气营业、中文学习、B 站归属感最强、热梗张口就来。
3. **2023 后营销期**：日式切片把她包装成"日本萝莉"，本人疲惫感渐显。
4. **2025-2026 毕业期**：沙哑、温柔、认真告别、最后"啊？"。

**复刻基准建议取 2-3 期（B 站观众最熟悉、语料最多的元气清楚期），屑和疲惫作为弹性点缀，不主导。**
